# Mosslume 0.5.2 · 攻击、角色素材与 Boss

本轮范围：修复武器与手脱节、统一仍使用原版的人物显示入口、直接接入用户给出的两个 Boss 和原始技能动画。AI 对话和行为保持本轮开始时的实现，光照、水面、风动不做重新设计。

## 武器与手

生成的身体帧和原版身体有不同的手臂位置，继续沿用原版臂长会让武器绕着错误的点旋转。当前以主角与五套居民的 144 个逐帧手位计算握柄位置，身体与武器使用同一个脚点、攻击时间和方向。装备继续调用原版物品绘制接口，保留真实斧、剑、弓的握柄、旋转、蓄力和特效层。

验证采用真实原版 `ItemAttackDrawOptions.pos` 形成的四边形，960 组覆盖六人物、四朝向、攻击进度和移动脚点。另有独立测试世界运行玩家真实 `tryAttack` 和五族居民的原生联网攻击动画，检查 12 个玩家武器/方向组合与 60 个居民武器/方向组合，并录制实际 framebuffer。

弓使用前伸持弓姿势，尚无单独的双手拉弦动作。原版少数后期复合武器使用另外的包装接口，不列入斧、剑、弓覆盖结果。详见 `WEAPON-HAND-ATTACHMENT-r8.md`。

## 人物一致性

农夫、工匠、商人新批次共 132 个姿势。每一族四向待机、行走、攻击保持同一发型、服装、头身比，脚底统一在 64px 帧的 `(32,52)`。阿朔、鹿安保留已有同批次动作。三族旧的搬运、睡觉、倒地人物因身份不一致停用，暂用同族站姿和既有状态变换；没有声称补出了不存在的专用姿势。

还要统一的不只是场景身体：原生地图头像、指令头像、社交思考头像各有独立绘制入口，需使用同一套人物的头部。运行审计以实际 mob ID、状态、纹理路径为准，避免把血条、持物或角度差异误认为原版人物。

## 直接使用用户 Boss 素材

用户明确要求使用已完成的角色与攻击图，不只是把它们作为重新生成的参考。原始 9 个文件已从废纸篓复制到 `mosslume/art/bosses-r8/references/`，不依赖废纸篓长期保留。

- 石符术士：直接接入原图的石柱、飞符动画与符纸、岩石特效。
- 白鬃镰客：直接接入原图的挥镰、渐隐突袭与斩光。
- 原文件是侧视素材，不能声称有原作者未提供的俯视四向。左右朝向使用原图及镜像，上下移动保留侧视角色表现。
- 原 GIF 帧时序保留；背景、色板小块由技术导出流程处理，保存原文件 hash、抠图规则和逐帧来源。不能通过重画改变人物设计来冒充直接素材。
- 源图没有真正的倒地帧，死亡使用已有角色淡出，不把受击白闪或突袭消失当作新死亡动画。

前面误解需求生成的两套 Boss 原图和导出文件保留为备用设计，本轮上线 Boss 应以用户原始素材为准。新的居民素材保留使用。

## 原生战斗接线

复用现有底座的 BossMob、行为树、联网技能广播、投射物、碰撞伤害、血条、物品、工作台配方和保存接口。每个 Boss 两种主技能，地面预警、释放、恢复分阶段；半血强化。召唤物仅在远离营地、地表有空地且附近没有其他首领时生效，失败不扣物品。没有往所有地图自动灌入 Boss。

Boss 生命、归属营地位置和强化状态进入原生存档；加载时重新回到安全的待机阶段，不重放存档前已发生的伤害。

## 验收边界与入口

唯一日常入口继续为 `~/Applications/Mosslume.app`，桌面入口指向它。存档仍在 `~/Library/Application Support/Mosslume-Life-Preview`，不因版本更新新建一个日常应用或存档目录。

运行测试用 `Mosslume-QA-Refactor-*` 独立目录，不调用付费模型。`--mod-path mod/dist` 可让已安装运行时读取待验收的 mod，而不覆盖仍在运行的日常应用。打包前必须正常保存并退出日常游戏，打包器拒绝写入运行中的应用。

最终包已覆盖唯一入口并正常打开主菜单，版本 0.5.2。用户先正常保存退出，更新前备份在 `build/r8-user-save-backup/20261025-042410`。应用保留相同资料目录；包内 mod 与本次构建完全一致，底座 kernel hash 未变。
