# Mosslume 0.5.1：角色动作与居民生活

日期：2026-10-25。延续 r6 的连续世界、原生玩法和既有光影，没有另换引擎。本文记录本轮实际改动和验收边界，不代表完整 PRD 已完成。

## 本轮改动

- 十二种怪物增加四方向攻击、受击、死亡，合计 480 个姿势、48 张运行条带；另从方向正确的动作复用 48 个静止姿势，保持战斗前后大小一致。死亡由原生死亡事件触发一次无碰撞的短时尸体动画，不延迟移除原生怪物，不重复掉落。怪物行走仍为静止图加局部步态，尚非完整四向行走序列。
- 阿朔、鹿安增加各 44 个四方向待机、行走、攻击姿势。客户端使用原生职业 ID 映射外观，避免依赖只存在服务端的模板元数据。搬运、睡眠、倒地仍有同角色待机或旋转兜底，其他居民也还共用职业外观。
- 三户住宅各补真实食物箱和三张原生座椅，分别一次供应 12 个苹果、6 个面包；十位常住人物一次获得一份原生携带口粮。使用原生库存、饥饿、进餐、座椅和工作系统，不直接改饥饿数值，不无限补货；原生 GND 标记经过保存后仍防重复。已有玩家物件不覆盖，玩家取消储物指派或拆除已供应物件后不自动恢复。
- 原生活动优先于短暂岗位访问。岗位访问错开时间、按居住区设置晚间地点；路径失败每人等待五秒再试，初次生活物件/储物注册失败也会重试。
- 修复自定义风动和水面渲染覆盖原生 recolor/overlay 纹理槽后没有恢复的问题。GL 2.1 的纹理状态隔离已离屏验证，包括嵌套、异常路径和原生活动纹理槽恢复。历史菜单 `unit 1` 警告早于本轮存在，不能声称这次已解决该特定警告。
- 水面静态岸线深度和四角数据改为有界、只读快照复用；流动与颜色变化继续由 shader 执行。没有降低画质、光源或风动数量。
- 用户反馈树不动后，实际旧录屏显示上半树冠四秒仅往返约 0.67 像素，树干固定。将树冠风动幅度从 0.026 调至 0.050、速度从 0.78 调至 0.90；CPU 阴影、合批与单株绘制共用常量。最终以新原生录屏复核，不能用绘制计数代替实际位移。

## 复用来源与美术

战斗时序、库存、座椅、工作、存档和区域加载继续复用原生系统。动画选帧延续已移植的 libGDX Animation；风动延续 Simple Wind Shader 2D 的根部权重与共享风场；既有 SDV-Radiance 表面光照、投影和 GDQuest 水面方案保留。本轮没有引入第二套引擎或新的模型服务。

美术由内置 imagegen 生成，所有提示词及原图位于 `mosslume/art/animation-r7/prompts.json`、`sources/`。导出清单为 `resident-export.json` 和 `monster-export.json`；导出器 `mosslume/scripts/export_core_residents_r7.py`、`export_creature_actions.py` 只机械裁切、同物种固定最近邻缩放、按脚点放入透明画布。沙虫使用修正朝向的 v2；复用 idle 逐种注明列号。

## 运行入口与自检
