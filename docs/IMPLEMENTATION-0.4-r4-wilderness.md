# 自然荒野预览 0.4.0-r4

## 世界生成的实际来源

之前的 v2 把六类地形固定在营地周围，并用放射状道路连接，属于素材展示布局。v3 已取消这个设计。

- `NativeFiniteTerrain` 适配本地 Necesse 1.3.3 `IslandGeneration.generateShapedIsland`、`generateRandomCellIsland` 的有限岛构造，直接使用原生 `GameRandom` 和 `GenerationTools.doCellularAutomaton`。适配层只生成数组，不调用会清空地图的原生构造函数。
- 海陆先生成，再选六种地形和建筑位置。保留最大连通大陆、外海边界、32 格安全森林出生区；这些约束属于 Mosslume。
- 植被使用原版随机细胞簇方案，额外保留行走间隙，取消 v3 偶数格刷树。
- `BiomeLayout` 仍负责六种地形的不规则边界、位置、建筑和营地小径；已有 FastNoiseLite 用于地形边界扰动，不代表完整地图生成器。
- 没有移植完整无限 `SurfaceLevel` 链、原版专用河流/湖泊模块、原版 POI/遗迹模板调度。本次没有引入另一套 GitHub 地图框架。

新建世界选择“自然荒野”。同种子确定生成，v1/v2 内容与地图回归指纹保持不变，已有存档不自动重绘。

## 已接入内容

六类地表、54 类植物/资源、5 类分层树、18 处带原生 20 格储物容器的建筑、9 类动物和 12 类怪物。资源通过原生伤害与掉落机制采集；实体通过原生 AI、生命、碰撞与存档运行。它们不是新增的大模型 NPC。

建筑分散在区域中，仅营地保留小径；每区首座建筑旁的工作台、火把和前院经过陆地与可达性检查。地表和道路边缘共享对应材质，继续使用现有光影、风动及水面渲染。

## 验证记录

- 编译通过，16 个回归测试程序通过。布局覆盖 9 个完整世界、32 个建筑放置压力种子；原生有限岛测试覆盖 4 个种子的连通性、确定性和植被间隔。
- 隔离原生运行 `wilderness-r4-20261024-diagnostic` 新建与磁盘重开通过。实际地图检查到 3,209 格安全森林、100 格营地道路，远处无放射路。
- 18 座建筑、108 个碰撞部件、12 处工作台/火把存在；原生采收有掉落。重开后储物标记、采收移除以及 21 个初始生物身份保持一致，没有重复生成。
- 六种地形各有实际引擎画面，昼夜营地画面已人工查看。证据在 `mosslume/validation/biomes-r4/`。
- 储物 UI 未做物理鼠标回归。早期 QA 在客户端远景尚未加载时直接调用开箱，触发客户端空对象错误；已取消该不成立的测试路径，当前仅核验服务端交互条件、容器与磁盘内容。
- 首次 Steam 冷启动未就绪；完成 Steam 初始化后运行成功。另一次早期探针出现服务器未响应，样本保留于 `build/refactor-evidence/wilderness-r4-20261024-native-b/`，不能把该样本的高帧率当作世界逻辑正常的证据。探针已加入远景超时与停机超时的线程诊断。

## 当前限制

建筑还没有独立室内和专属生产流程。怪物缺完整四方向行走/攻击动画；悬崖高差模块尚未接入。群系接缝仍按原生格子分界，湿地水道与火山岩浆规则也未完成。本轮没有修改模型供应商或进行付费模型请求。

独立应用为 `~/Applications/Mosslume Biomes Preview.app`（应用版本 0.4.4），资料目录为 `~/Library/Application Support/Mosslume-Biomes-Preview`，不会覆盖稳定版资料目录。

## 最后一次运行与交互入口修正

同包 `wilderness-r4-20261024-final` 新建、六区加载与正常保存退出通过；12 秒无截图采样平均 59.51 fps，p95 20.67 ms，最大 35.97 ms。此为短样本，既不证明长局稳定，也未确定早期服务器忙循环的根因。

随后根据用户反馈调整伙伴入口：靠近健康的已登记伙伴右键交互打开聊天，输入框移到面板上部，支持回车发送；原版交易/营地管理与重伤救治继续保留。普通启动不带 QA 固定镜头参数。此次入口修改仅编译检查，按用户要求未继续运行自动 QA 或调用付费模型。聊天仍不长期存档，性格演化尚未实现；已有共同任务经历仍可检索。

## 后续交互修订 0.4.5（2026-10-24）

上述侧栏聊天入口已改为世界内交谈：靠近健康的友好人形 NPC 右键，底部显示一行输入。玩家发言与角色回应分别使用原生 HUD、字体布局和气泡皮肤，跟随说话者与镜头；长句分页，避免两个气泡直接遮盖。Enter 发送，Esc 关闭，失焦不发送。等待回应时可以继续写草稿，发送按钮暂时禁用，窗口缩放保留输入焦点。

侧栏仅用于已招募伙伴的分工和共同经历。聊天栏保留“事务”和已招募伙伴的“分工”；原生交易、招募、救治入口继续使用原有权限与距离检查。

登记范围扩展到已加载的友好 HumanShop（包括村民、商人、旅人），并未增加出生人口。未招募角色可聊天，不能接受玩家的营地任务；普通动物与怪物继续使用原生行为。

每名角色保存最近 8 组真实问答，随世界存档。只有客户端接纳的回复才能入库，取消、超时、切图及退出世界有请求绑定与队列清理。角色自己的原生存档增加 UUID，跨图/重载按稳定身份匹配，旧存档以原地图、数字 ID、名字及可用身份字段严格迁移。近期问答不等于长期语义记忆、关系成长或主动社交，这些仍未完成。

新增 UI 与后端已统一编译（126 个 Java 源文件、264 个类）。CompanionWorldSaveTest 与 DeepSeekProviderTest 的离线检查通过，覆盖问答持久化、取消/切图/卸载、重复确认、角色身份及未招募角色权限。本轮未运行自动原生 QA、未调用付费模型，因此不声称已完成真实点击与画面验收。

独立包为 `~/Applications/Mosslume Dialogue Preview.app`，版本 0.4.5。使用原来的 `Mosslume-Biomes-Preview` 存档目录；需先在旧游戏保存退出，再启动新包。当前运行中的旧应用没有被结束或覆盖。

GitHub 方案复核见 [AI NPC 开源方案](research/ai-npc-options-20261024.md)。AgentScope Java、Mem0 仅完成研究，尚未引入；现有 AI Town 复用仍是记忆排序的局部移植。
