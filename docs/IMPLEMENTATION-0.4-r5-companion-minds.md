# 伙伴记忆与主动社交 0.4.6

本次在现有 Java 17 游戏中接入 AgentScope Java，并移植 AI Town 可分离的记忆与社交流程。保留现有地形、光影、树木风动和原生任务执行。

## 实际来源

- AgentScope Java 稳定版 **2.0.4**，官方 `v2.0.4` 对应提交 `0b6743b263ba8e39eb417e35048026f1e0196548`。实际执行 `OpenAIChatModel → DeepSeekFormatter → Msg / ToolSchema → ChatResponse`，不是只保留 HTTP 调用再贴框架名称。八个依赖按 SHA-256 锁定；详情见 `mod/dependencies/README.md`。
- AI Town 固定提交 `8e05997f2409275669c8344b84a51692e83f3f33`。移植记忆相关性/重要性/新近程度排序、访问节流、按重要性触发且关联证据的整理，以及邀请、接受、靠近、交替交谈、离开、冷却与超时流程。上游源码和 MIT 许可在 `third-party/ai-town/`；随包许可与移植范围在 `mod/resources/third-party/ai-town/`。
- AgentScope 依赖置于应用 `Game/lib`，不合并到 mod jar。原生加载器会扫描 mod 内的每个 class，外置能避开未使用模块的可选依赖。启动器以显式 classpath 加载现有内核和这些库，内核文件保持原校验值。

## 玩家可见行为

玩家和友好人形角色继续使用头顶气泡。玩家自述的称呼、常见喜好、约定与重要共同经历单独保存，不受最近八组聊天上下文淘汰。角色会区分“你说过”与“实际发生过”；模型回复不能自行成为完成任务或救援的事实。

信任、谨慎与社交倾向逐步成长。真实工作成功、失败、重伤和恢复会产生不同影响；同类事件限频，重复普通聊天不会无限刷信任。单凭从重伤恢复不能认定玩家实施过救援。危险任务结合当前伤势、附近敌人、昼夜、谨慎和信任进行判断，拒绝时会在角色头顶说明；取消、回住所和原生任务权限继续保留。

空闲、未被玩家占用且符合条件的角色会邀聊，通过原生寻路靠近，然后交替说话。访客不会被强行赋予玩家命令权限，可与已在附近的人原地交谈。真实任务完成、恢复活动、近距离重伤求救和夜间提醒有较高优先级。

共同经历页新增“相处 / 记得的事 / 来往”，显示自然语言性格状态、仍有事件依据的回想、分类长期记忆及实际交谈过的人物。NPC 数量仍由世界生成和招募系统决定。

## 线程、任务与持久化

`NpcMind` 仅由服务器线程修改，发布不可变快照供 UI 和模型构建上下文。异步模型只返回文本或受限意图，不能操作原生角色对象。客户端接纳玩家对话后才提交记忆回执；世界、角色、地图和请求票据均参与验证。

`NpcSocialPlanner` 每半秒接收邻近角色的快照；寻路、原生工作检查和任务释放由 `NpcSocialRuntime` 在服务器执行。社交命令只占用空闲伙伴，不代替玩家任务；新指令会中断社交。仅释放仍属于该次社交的原生命令，存档记录未结束的移动标记，读档后清理遗留控制。

社交会话本身不恢复；已报告事件、夜晚提醒、最近社交时间及 NPC 关系会保存。每人、每对角色、全局消息均有限频，并设路径与交谈超时。记忆最多 128 条、证据整理最多 8 条、人物关系最多 24 个。

模型只在部分自主发言时调用，主动社交的模型调用最多每两分钟一次，三秒内无结果则使用有事实依据的本地台词。玩家交谈优先。现有日请求/费用预算与取消机制继续生效。普通离线 QA 不加载真实模型配置，只有明确付费探针才允许外部模型请求。

## 能力边界

长期检索使用中文双字/词匹配与 AI Town 排序，没有向量数据库。偏好抽取支持常见明确自述，不是任意自然语言知识图谱。约定保留为待验证陈述，尚无通用承诺履约任务链。

事件整理是带真实证据引用的确定性归纳，没有额外调用模型生成反思。人格成长目前为三项有界倾向，影响表达、社交和风险判断；没有完整情绪模拟或无限制自我规划。

主动邀聊的时机、移动和权限由游戏状态机决定，模型负责部分自然表达。动物和怪物继续使用原生战斗和生态 AI。没有接入 Mem0、完整 AI Town 服务或 AgentScope 的通用文件/终端工具。
