## 当前限制

- 伙伴初始已在营地，招募事件、个人剧情、阶段目标与关系内容尚未完成。
- 采收与搬运目前按原生一批工作执行，尚不支持“精确 20 个材料送到指定箱子”的完整组合任务；采收产物不等于已经入仓。
- 原生救援入口已接入，完整救援引导、恢复期、护送与治疗床仍需后续内容和验收。
- 自然语言输入在未配置模型时禁用；没有伪装成模型的离线聊天。模型摘要、预算、在线断网恢复留待模型适配器确定后验证。
- 初始房屋和多个结构锚点已支持，任意玩家自建墙体自动生成整栋原创屋顶、多个自建住宅的完整表现尚未完成。
- NPC 工作/搬运各只有一个基础姿势，攻击复用原创身体与原生工具图层；完整四向工具、战斗、受击动画仍需补充。动物、敌人及更多 UI 的原创素材替换也未全部完成。
- 新地形的通用内容入口已存在；船只、温度等新的游戏规则仍须实现，不能只加图片获得新机制。

## 保存隔离与运行

预览应用：`~/Applications/Mosslume 0.4 Preview.app`。日常资料：`~/Library/Application Support/Mosslume-0.4`。不自动复制旧存档；原 `Mosslume.app`、`Mosslume S1 Preview.app` 和稳定标签保持可回退。

打包改为原子替换运行文件，避免反复覆盖已签名 Mach-O 的同一 inode 后触发 macOS `Taskgated Invalid Signature`。原有 Steam 依赖和验证流程保留。

生成图片使用内置 imagegen。原图及最终提示词在 `mosslume/art/characters/residents/animations/`，技术裁切导出脚本为 `mosslume/scripts/export_resident_animations.py`，运行文件清单为 `mosslume/runtime-art/residents/animations-v1-manifest.json`。

## 验证口径

`scripts/check_refactor.py` 负责布局、版本/内容一致性、场景坐标、GND 零值、任务/记忆保存及原生回调回归。`scripts/run_refactor_probe.py` 仅在独立 QA 资料目录操作，通过与 UI 相同的意图队列及原生服务器回调验证任务和存档。

已通过的 `woodland-r4` 原生检查包括新世界、704 个边界采样、原生制作扣料/产出、无效配方拒绝、箱子保存、洞穴梯子往返、跟随/守卫/回住所/取消。重启后原生库存、箱子标记、伙伴身份、事件和已取消任务一致恢复。

首个 `forest-r1` 性能段在两个 Java 窗口并行期间采集，不能与旧版单窗口 55.6 fps 直接比较，也不能用于宣称性能达标。自动检查没有模拟真实鼠标点击；原生窗口控制工具本轮无法可靠连接 Java 窗口，不能把方法调用检查写成物理输入验收。

`harvest-r3` 已完成真实成熟作物采收、执行中取消、再次采收；成熟作物从 12 处变 10 处，真实作业产出小麦，无作物/物品注入。NPC 实际绘制记录包含站立、行走、工作和搬运，24 张状态纹理全部载入，站姿缺图回退为 0。倒地与睡眠素材的完整实机姿态尚未单独验收。

修复了首次工作等待中的原生 5～10 秒冷却误判，以及重连覆盖个人床位复活点和自定义营地名的问题。`forest-final` 的新建与重载检查通过：伙伴身份、任务、记忆、箱子和制作结果一致，个人床位复活点与重命名营地也保留。白天草地 shader 实际运行，昼夜截图已检查；风动和投影 GPU 正常、无 fallback。旧固定岛也重新捕获，岸边向海面投影仍生效。所有证据留在 `mosslume/validation/refactor-0.4-r1/`。


## 性能定位与收敛

JFR 的调用栈采样定位到地面光照坐标缓存的哈希碰撞，以及每次绘制构建的灯光参数数组、动态参数名和 uniform 查询函数。修复为相机范围内的坐标数组缓存、视域外兼容缓存与固定参数名，保留原有 120ms 缓存周期和光照公式；相同相机观察也避免重复创建查询边界。额外回归覆盖负坐标、边缘采样点、窗口变化、地图切换和缓存内容等价。

JFR 摘要按游戏绘制栈筛选，用于定位热点；分配权重不是逐字节精确内存统计，也不把样本比例直接写成帧耗时。原始记录保留在本地 build 目录，没有发布游戏日志、存档或完整运行记录。


最终包编译及 10 个测试程序通过，Mac 签名校验及安装包与构建 JAR 一致性通过。最终原生检查通过，昼夜截图已再次检查。任务与保存代码在渲染优化期间未改变，复用已通过的真实采收和重启证据，没有为同一逻辑无理由重复全套测试。

**性能门槛仍未通过。** 最终 30 秒未截图测量平均 27.4 fps、p95 67.8ms、13 个超过 100ms 的长帧；本轮不同条件短测在约 27–43 fps 之间。缓存修复消除了有证据的低效查找与分配，但这组运行没有证明整体帧率改善。不能把该包标成稳定 60 fps、全量 PRD 完成或最终质量验收通过。下一步应继续处理绘制提交及完整帧时间，暂不继续扩大系统范围。
