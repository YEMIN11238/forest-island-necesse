# Mosslume · 苔光之岛

## 0.3 S2 道路、人物与投影

当前独立预览已经更新。连续小径按真实相邻地块拼接圆顺转弯、宽度变化和草地边缘；原生泥地会自动长回草地的问题通过新增稳定小径类型修复。旧档仅迁移一次固定初始路线上未由玩家铺设的草/泥地，保留木地板、农田与玩家改造。测试保存后核验为 73 格稳定小径和 1 格原木地板。

主角换为新生成的紧凑头身像素稿，实际身体约 64–66 世界像素，采用整数 2 倍显示；四向站立与四帧行走按实际移动距离播放。工具攻击保持同一身体，并叠加方向对应工具动作。人物原图、生成提示词和运行导出分别在 `art/characters/player/player-compact-v2.png`、同名 `.prompt.txt` 与 `runtime-art/`。居民保留四向静态稿，尚未补齐步行动画。

照明改为共享的昼夜环境与暖色局部光场，树冠及物件按表面位置受光。实际移植 SDV-Radiance 的地面轮廓投影数学，在原生 OpenGL 中以 GPU 全分辨率遮罩合成，最多 8 个可见投影光源；岸线使用实际土地/水域边界，树影跟随同一风动网格。它是投影组件的移植，并非整个 Radiance 管线。源代码版本与 MIT 许可在 `third-party/SDV-Radiance-shadow/`。

夜景亮度追加修正：深夜陆地环境光 RGB 调为 `(0.28, 0.36, 0.48)`，海面为 `(0.20, 0.30, 0.46)`；火把、营火、窗户照明半径分别收至 144、176、104 世界像素，减少大面积重叠照亮。保留火焰和窗户自发光。实际 21 点/12 点同视角检查在 `build/evidence-s1/s2-night-tuning/`，已查看原生截图确认暗处轮廓、道路与局部暖光可辨；6 秒独立性能段平均 55.6 fps，仅作短测记录。

10 秒原生渲染检查为 `build/evidence-s1/s2-final/`：夜景性能段不含截图，10 秒平均 57.8 fps，p95 25.5 ms，4 帧超过 50 ms。后续录制段比较 21 点与 12 点光照；截图、真实采样时间与视频均保留。首次 CPU 投影约 12 fps 的失败试验及中间 GPU 版本均保留作诊断，未用它们作为交付帧率。之后修正了诊断工具的退出保存时序，独立 2 秒保存检查约 45.8 fps，保存后实际解析确认 73 格稳定小径；短测波动仍存在。完整记录见 `build/evidence-s2/verification.json`。尚未达到稳定 60 fps，也未达到参考视频完全一致的水面、布局与物件间表面遮挡。

桌面 `Mosslume 画面预览.app` 指向当前独立预览。日常 0.2 应用未覆盖，当前资料目录仍为 `Mosslume-S1`。S1 适配器回滚包在 `build/baseline-s1/`。

## 0.3 S1 视觉基线

本轮依据 [视觉重做 PRD](docs/PRD-0.3-visual-rebuild.md) 完成代表性场景的显示与风动接入：Sharp Shimmerless 最终像素缩放、像素贴图 NEAREST、整数树木/小屋倍率，以及 Simple Wind Shader 2D 的连续 GPU 网格形变。移动叶缘采用已有 CC0 亚像素覆盖，树干保持固定。光影、水面与整岛布局仍属于后续阶段，当前不能称为参考画面的完整复刻。

独立测试应用为 `~/Applications/Mosslume S1 Preview.app`，默认资料目录为 `~/Library/Application Support/Mosslume-S1`。日常 0.2 应用和个人存档保留，回滚副本在 `build/baseline-0.2/`。第三方固定源码、许可证和改动记录在 `third-party/`，实际原生截图、时序帧及帧时间记录在 `build/evidence-s1/`。

构建脚本现在默认打包 S1 预览；只有显式添加 `--install` 才替换日常应用。原生对照工具见 `scripts/VISUAL-PROBE.md`；旧的失焦节能测量保留作诊断记录，正式前后比较使用 `legacy-controlled` 与 `new-controlled`，不把截图录制阶段计为运行性能。

## 0.2 运行基线

可运行的 Mac 开发版本，0.2.0。应用位于 `~/Applications/Mosslume.app`，桌面也有同名入口。使用用户选定的像素背包图片作为应用图标。

启动显示原创 Mosslume 首页，点击“进入小岛”读取固定的 ForestIsland 地图。首次使用会把旧版小岛存档复制到新的 `~/Library/Application Support/Mosslume`，原应用和原存档保留。

当前复用本机已恢复并修复的 Necesse Java 内核及已有固定岛屿适配。采集、掉落、库存、箱子、制作、种植、居民和存档继续由原生系统负责。本次没有重新写一个浏览器演示替代现有游戏。

## 当前接入

- 首页背景、三个操作按钮、加载画面、独立窗口名称与应用图标。
- 主角四方向站立、四帧行走，以及方向对应工具叠加动作；攻击判定仍走原生逻辑。

- 原创铁砧、村庄公告牌、幼树、小麦/胡萝卜/南瓜生长状态，以及分层小屋门窗与屋顶遮挡。
- 两名原生居民在日常站立/行走时使用原创四方向形象；职业行为与关系系统仍由底座负责。
- 保留此前树冠摇动、火焰8帧、烟雾、上升荧光、海洋颜色变化、局部光照和投影。

## 操作

WASD移动，数字键选择快捷栏，左键使用工具/放置，右键交互，E打开背包和制作，Esc暂停或返回首页。存档沿用原生保存流程。

## 构建

```sh
python3 scripts/build_game.py
```

复用已构建的内核；只有修改内核时才追加 `--rebuild-kernel`。运行导出脚本需要工作区捆绑的 Python/Pillow，Java适配编译需要现有JDK21，应用打包需要Xcode Command Line Tools。

## 目前的边界

这是首个素材接入版本。角色步态仍需精修；工具动作目前侧向为主；居民尚无完整职业动画。UI窗体和部分物件仍沿用底座，尚未声称42个物品源图、全部家具与装饰都已覆盖完整原生清单。睡眠、骑乘和战斗中的少数绘制路径保留原生呈现，避免破坏既有交互。

地板拼缝、房屋遮挡线、自由建造全方向模块仍待打磨。AI对话与AI居民决策尚未接入。本开发版本仍需要已安装并登录的Steam；启动器会尝试打开Steam，不修改认证逻辑。

源码适配位于 `../necesse-island/mod/src/localforest/`，美术原图位于 `art/`，运行导出及来源记录位于 `runtime-art/manifest.json`，打包记录位于 `build/package-manifest.json`。没有改动Steam购买版安装目录，也没有自动上传GitHub。
